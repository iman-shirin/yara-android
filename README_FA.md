# یارا – نسخه پایه اندروید (0.1.1)

این بسته سورس Android-first یارا است و شامل رابط فارسی، مکالمه متنی، ذخیره تاریخچه روی دستگاه و اتصال به سرویس‌های سازگار با OpenAI Chat Completions است.

## ساخت APK آزمایشی

ساخت APK از طریق GitHub Actions تعریف شده است:
1. در مخزن GitHub، به زبانه Actions بروید و workflow با نام Build Android APK را اجرا کنید؛ یا پس از push روی شاخه main/master به‌صورت خودکار اجرا می‌شود.
2. پس از پایان موفق، از صفحه اجرای workflow بخش Artifacts، فایل Yara-Android-debug را دریافت کنید.
3. ZIP آرتیفکت را باز کنید و app-debug.apk را روی گوشی نصب کنید. برای نصب خارج از Play Store ممکن است Android اجازه نصب از منبع مربوطه را بخواهد.

پیش‌نیاز build: JDK 17، Gradle 8.9، Android Gradle Plugin 8.7.3 و Android SDK Platform 35.

## پیکربندی مدل

در برنامه وارد «تنظیمات» شوید و Base URL، نام مدل و API Key را وارد کنید. نمونه پیش‌فرض Base URL برابر https://api.openai.com/v1 و نام مدل نمونه gpt-4o-mini است؛ دسترسی واقعی به مدل به حساب و سرویس‌دهنده شما بستگی دارد. کلید API را در مخزن عمومی یا پیام چت قرار ندهید.

## وضعیت پیاده‌سازی

**موجود در این نسخه:** رابط فارسی، گفت‌وگوی متنی، تاریخچه محلی، اتصال یک provider سازگار با OpenAI، صفحه تنظیمات و workflow ساخت APK آزمایشی.

**هنوز پیاده‌سازی نشده:** چند provider مستقل و fallback خودکار، رمزنگاری کلید با Android Keystore، Room و جست‌وجوی معنایی، گفتار فارسی STT/TTS، چهره متحرک، وظایف و یادآوری، کنترل مجاز قابلیت‌های گوشی، آزمون‌های خودکار و انتشار release امضاشده.

این مخزن سورس است، نه APK. APK فقط پس از اجرای موفق workflow و دریافت artifact ساخته‌شده قابل تأیید است. خروجی فعلی debug است و برای انتشار عمومی/تولیدی مناسب نیست.

# یارا – نسخه پایه اندروید (0.2.0)

این بسته سورس Android-first یارا است و شامل رابط فارسی، مکالمه متنی، ذخیره تاریخچه روی دستگاه و اتصال چندسرویسه به APIهای سازگار با OpenAI Chat Completions است.

## ساخت APK آزمایشی

ساخت APK از طریق GitHub Actions تعریف شده است:
1. در مخزن GitHub، به زبانه Actions بروید و workflow با نام Build Android APK را اجرا کنید؛ یا پس از push روی شاخه main/master و بازشدن Pull Request به‌صورت خودکار اجرا می‌شود.
2. پس از پایان موفق، از صفحه اجرای workflow بخش Artifacts، فایل Yara-Android-debug را دریافت کنید.
3. ZIP آرتیفکت را باز کنید و app-debug.apk را روی گوشی نصب کنید.

پیش‌نیاز build: JDK 17، Gradle 8.9، Android Gradle Plugin 8.7.3 و Android SDK Platform 35.

## پیکربندی سرویس‌ها

در تنظیمات برنامه، برای هر سرویس نشانی پایه، مدل و کلید مستقل تعریف می‌شود:

- **Groq (اصلی):** https://api.groq.com/openai/v1 — مدل پیش‌فرض openai/gpt-oss-120b
- **Gemini (جایگزین):** https://generativelanguage.googleapis.com/v1beta/openai/ — مدل پیش‌فرض gemini-3.8-flash

با فعال بودن گزینه جایگزینی خودکار، در خطاهای شبکه، محدودیت نرخ (HTTP 429)، timeout (HTTP 408) یا خطاهای سرور (5xx)، یارا یک بار درخواست را از Gemini پیگیری می‌کند. خطاهای پیکربندی و احراز هویت (مانند 400 و 401) به‌صورت خودکار پنهان نمی‌شوند.

کلیدها با AES/GCM و کلید محافظت‌شده توسط Android Keystore ذخیره می‌شوند. کلیدها را در مخزن کد یا پیام چت قرار ندهید. کلید Gemini را می‌توان از https://aistudio.google.com/apikey دریافت کرد. دسترسی رایگان به مدل‌ها و سهمیه‌ها تابع شرایط حساب و محدودیت‌های Google است و رایگان بودن نامحدود تضمین نمی‌شود.

## وضعیت پیاده‌سازی

**موجود در این شاخه:** رابط فارسی، گفت‌وگوی متنی، تاریخچه محلی، تنظیم مستقل Groq و Gemini، ذخیره امن کلیدها، fallback محدود و خودکار از Groq به Gemini و workflow ساخت APK آزمایشی.

**هنوز پیاده‌سازی نشده:** انتخاب آزاد هر provider به‌عنوان سرویس اصلی از داخل UI، مسیریابی هوشمند وظیفه‌محور، Room و جست‌وجوی معنایی، گفتار فارسی STT/TTS، چهره متحرک پیشرفته، وظایف و یادآوری، کنترل مجاز قابلیت‌های گوشی، آزمون‌های خودکار و انتشار release امضاشده.

این مخزن سورس است، نه APK. خروجی فقط پس از اجرای موفق workflow و دریافت artifact ساخته‌شده قابل تأیید است. خروجی فعلی debug است و برای انتشار عمومی/تولیدی مناسب نیست.

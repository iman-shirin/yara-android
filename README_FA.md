# دستیار هوش مصنوعی یارا – Android 0.3.7

این مخزن سورس برنامه اندرویدی یارا است. نسخه 0.3.2 اصلاحی برای بسته‌بندی آفلاین موتور نمایش آواتار سه‌بعدی است؛ وابستگی‌های Three.js و three-vrm در زمان ساخت به یک فایل JavaScript محلی تبدیل می‌شوند تا WebView هنگام اجرا برای دریافت کتابخانه‌های رندر به CDN وابسته نباشد.

## ساخت APK آزمایشی

ساخت از طریق GitHub Actions انجام می‌شود:
1. اجرای workflow با نام **Build Android APK** یا باز کردن Pull Request به شاخه `main`.
2. پس از موفقیت همه مراحل، فایل ZIP مربوط به Artifact را از صفحه Actions دریافت کنید.
3. فایل `app-debug.apk` را از ZIP خارج و روی دستگاه ARM64 با Android 8.0 یا بالاتر نصب کنید.

پیش‌نیاز ساخت: JDK 17، Gradle 8.9، Android Gradle Plugin 8.7.3، Android SDK Platform 35 و Node.js/npm برای bundle کردن آواتار.

## اتصال مدل‌های هوش مصنوعی

در تنظیمات برنامه، نشانی پایه، نام مدل و کلید سرویس‌ها وارد می‌شود:
- **Groq (اصلی):** `https://api.groq.com/openai/v1`
- **Google Gemini (جایگزین):** `https://generativelanguage.googleapis.com/v1beta/openai/`

در صورت فعال بودن fallback، خطاهای شبکه، timeout، محدودیت نرخ و خطاهای سرور می‌توانند باعث تلاش مجدد از طریق Gemini شوند. کلیدها با AES/GCM و کلید محافظت‌شده توسط Android Keystore نگهداری می‌شوند. کلید API را در مخزن کد یا گفتگو منتشر نکنید.

## وضعیت قابلیت‌ها

### پیاده‌سازی‌شده در سورس
- رابط فارسی و راست‌چین مبتنی بر Jetpack Compose
- گفتگوی متنی با Groq و Gemini از طریق API سازگار با OpenAI Chat Completions
- انتخاب Groq یا Gemini به‌عنوان سرویس اصلی از تنظیمات و استفاده از سرویس دیگر به‌عنوان جایگزین خودکار
- ذخیره امن کلیدها با Android Keystore
- ذخیره تاریخچه گفتگو به‌صورت محلی
- حافظه بلندمدت مستقل از مدل در SQLite؛ متن حافظه با AES-256-GCM و Android Keystore رمزگذاری می‌شود
- یادآوری یک‌باره با اعلان Android، ذخیره پایدار و بازیابی زمان‌بندی پس از راه‌اندازی مجدد گوشی؛ زمان‌بندی از نوع inexact است و ممکن است با تأخیر سیستمی اجرا شود
- مدیریت محلی کارها: ثبت، فهرست کارهای باز، مشاهده کارهای تکمیل‌شده، تکمیل و حذف؛ عنوان کارها با Android Keystore رمزگذاری می‌شود
- جستجوی وب با DuckDuckGo HTML، استخراج عنوان، خلاصه و نشانی منابع و ارسال نتایج به مدل برای پاسخ مستند؛ نتایج وب به‌عنوان داده غیرقابل‌اعتماد تلقی می‌شوند
- فرمان‌های فارسی حافظه: «به خاطر بسپار: ...»، «فراموش کن: ...»، «فهرست حافظه»؛ حافظه‌های مرتبط به‌صورت زمینه به مدل ارسال می‌شوند
- فرمان یادآوری: «یادآوری فردا ساعت 09:30 | متن»، «یادآوری 2026-11-13 09:30 | متن»، «یادآوری‌ها» و «حذف یادآوری شناسه»؛ در Android 13 به بالا مجوز اعلان لازم است
- فرمان کارها: «کار جدید: ...»، «کارها»، «کارهای انجام‌شده»، «انجام شد 123» و «حذف کار 123»
- فرمان جستجو: «جستجو: عبارت موردنظر» یا «در اینترنت جستجو کن: عبارت موردنظر»
- ورود گفتار با Android SpeechRecognizer و درخواست زبان `fa-IR`؛ کیفیت و دسترس‌پذیری وابسته به سرویس گفتار نصب‌شده روی دستگاه است و آفلاین بودن آن تضمین نشده است
- تولید گفتار فارسی با Sherpa-ONNX و مدل Piper `fa_IR-amir-medium`؛ مدل در اولین استفاده دانلود و سپس به‌صورت محلی اجرا می‌شود
- آواتار VRM با پلک، حرکت سر و حرکت دهان هنگام پخش گفتار
- بسته‌بندی محلی فایل JavaScript رندر آواتار در فرایند CI؛ پس از ساخت صحیح، اجرای renderer به CDN وابسته نیست

### تکمیل‌نشده یا تأییدنشده
- افزودن ارائه‌دهندگان دلخواه خارج از Groq/Gemini، مسیریابی وظیفه‌محور و انتخاب خودکار مدل محلی/ابری
- Room و جستجوی برداری/RAG پیشرفته؛ جستجوی حافظه فعلی مبتنی بر هم‌پوشانی واژگانی محلی است
- رابط گرافیکی اختصاصی برای ویرایش و مدیریت پروژه‌های حافظه
- وظایف دارای سررسید، اولویت و تکرار خودکار؛ همگام‌سازی وظایف با سرویس‌های خارجی
- جستجوی وب از منابع جایگزین در صورت مسدودشدن DuckDuckGo، کش نتایج و مدیریت منابع در رابط کاربری
- اجرای ابزارهای عمومی و کنترل قابلیت‌های گوشی
- اتصال Android به Windows
- یادآوری‌های تکرارشونده و تبدیل زبان طبیعی آزاد به زمان‌بندی پیچیده
- مکالمه پیوسته و تشخیص گفتار آفلاین مستقل
- همگام‌سازی دقیق واج‌به‌واج حرکت لب
- Release APK امضاشده و انتشار تولیدی

## آزمون و محدودیت اعتبارسنجی

موفقیت Gradle و تولید Artifact فقط ساخت نرم‌افزار را تأیید می‌کند. تست‌های واحد فرمان‌های حافظه را پوشش می‌دهند، اما آزمون‌های رابط و دستگاه واقعی هنوز لازم‌اند؛ نصب و اجرای واقعی روی Galaxy A52، تشخیص و تلفظ فارسی، دانلود مدل Piper، رندر WebGL و انیمیشن آواتار باید روی دستگاه واقعی آزمایش شوند. تا انجام این آزمایش‌ها، این موارد «تأییدنشده» هستند.

خروجی فعلی Debug APK است و برای انتشار عمومی نهایی محسوب نمی‌شود.
